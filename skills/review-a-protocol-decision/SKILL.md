# Review a protocol decision

Use after an analysis has selected observations, applied a rule or declared that a result cannot be determined.

1. Find the passage that governs the decision. Identify the unit it applies to, the evidence it requires and any condition that changes its scope.
2. Work forward from the original records. For one accepted record and one nearby rejected record, write down the evidence and the clause that decides each. If all records receive one decision, check the closest boundary case and explain why it belongs there.
3. Apply the same reasoning to the full population. Reconcile the selected identifiers or counts with the saved result, then follow any change through to the conclusion. For an unresolved decision, identify the missing fact and check whether another supplied source provides it.
4. Read the delivered answer against the request. Preserve decisions supported by the evidence. If two readings still matter, state which source or clarification would settle them.

Keep the evidence trail in working notes when the requested deliverable has a fixed format.
