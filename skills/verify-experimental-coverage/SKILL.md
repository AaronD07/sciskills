# Verify experimental coverage

1. Read the governing protocol and its authorized changes. Write the identity of each required experiment, including the settings that make two runs scientifically distinct.
2. Reconstruct the work from execution evidence. Map attempts and their saved outputs back to those identities. Distinguish an attempted experiment with an unfavorable outcome from one never performed.
3. Reconcile both inventories. For a discrepancy, follow the input and output through the records. When the assignment permits recovery, execute the missing work and verify its product.
4. Report the supported coverage and scientific conclusion. Preserve legitimate results and make any remaining limitation specific enough for the next investigator to resolve.
