# Review a numerical result

Use after the analysis has produced a number someone will rely on.

1. Read the request and the saved result. Write down what the main number measures, its units, the population it describes and the form the reader requested.
2. Start a fresh calculation from the source. Use a different route from the draft where possible. For an aggregate, keep the observations or group totals that contributed. For a comparison, reconstruct each side before calculating the difference.
3. Predict a sign, range or limiting case and check it. If the two results disagree, trace the first discrepancy to a record or a method choice. Change the draft only when the evidence settles it.
4. Open the final deliverable. Check that its values, units and conclusion agree with the calculation and that the requested values can be read directly.

A matching total can hide offsetting errors. Inspect a contributing observation when the calculation has several stages. Keep working notes outside a machine-readable answer.
