# Test a competing explanation

If a proof, exact calculation or exhaustive check settles the claim, verify it directly. Use the comparison below when a substantive choice remains.

1. Identify the choice that matters most to the result. Look at how the draft arrived at it. Which alternatives could that procedure actually have found?
2. Choose a credible alternative outside the range already explored. Use the task's evidence to say what observation or prediction could distinguish the two. Keep the original result so either one can win.
3. Run the smallest comparison that could change the decision. Give both alternatives the same data, constraints and scoring rule. If they agree on the measurements used to choose them, compare a further consequence when the task permits it.
4. Carry the better-supported choice through to the requested deliverable and check it there. If the comparison is inconclusive, keep what the evidence supports and state which claim is still uncertain.

## Exercise

Two explanations for an instrument's drift are a constant offset and a change in sensitivity. Fit each to two calibration readings. Choose a third reference reading that would distinguish their predictions, then describe how its value would affect the correction.
