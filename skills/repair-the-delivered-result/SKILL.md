# Repair the delivered result

1. Open the submitted artifact as its next user would. Identify the quantities or conditions that must hold together for the result to be usable. Start with the one for which the draft has the weakest direct evidence. A successful intermediate calculation can coexist with a wrong final result.
2. Build a small independent check from the original specification. Choose an input for which you can establish the answer by another computation, an exact case or an observation set aside from fitting. Use the requested observation rule, units, constraints and output format. Run the saved artifact and record the expected and actual result.
3. If the draft explains the observations but its solution is ambiguous, construct a genuinely different feasible candidate. Give both candidates the same data and budget, then compare a prediction that distinguishes them. For an exact claim, a proof or exhaustive check can settle the question directly.
4. When a discrepancy matters, trace it to the earliest incorrect decision and repair the delivered file. Rerun the failing check, a case that previously worked, and the full requested workflow when feasible. Keep an improvement only if it survives those checks. If uncertainty remains, deliver the verified part and identify the unresolved quantity.

## Exercise

Review a sensor calibration fitted on a narrow temperature range. Use an independent calibration reading to test the reported concentration, then check that any correction still works on a previously accurate reading.
