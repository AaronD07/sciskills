# Scientific integrity review study

This study compares ordinary review, a general evidence-review skill and a specialist skill against the same scientific draft. Tasks concern experimental coverage, measurement provenance and deployment validity. A compromised upstream report or input is a constructed test condition. Its presence alone never counts as a model error. A review repairs a critical error only if the first draft contains it and the resulting decision passes the hidden scientific checks.

## Qualification

Each family has three development sources and six fresh holdout sources. Each source supplies an intact and a compromised packet with the same request. Every packet gets a fresh draft from Luna, Terra and Sonnet. Freeze packet hashes, references, consequential fields and severity rules before collecting a family's development drafts. Qualify a family when at least two independent development sources elicit a material error on the predeclared gate fields. One model or twin can establish an error on a source. Repetitions within a source count once. Infrastructure failures, missing submissions and mere formatting errors cannot qualify a family. Inspect flagged drafts against their governing records before releasing the gate. Retain the full archive and report ambiguous cases.

## Study arms

Holdout sessions use fresh workspaces. For each original draft, independently restore the same files, source material, prior Python operations and final message. The ordinary reviewer receives the standard review request. The general reviewer also receives the general card. The specialist reviewer also receives the card chosen by deliverable type before opening the packet. Routing is identical across twins. Language models have no access to hidden reference calculations, graders, twins, case IDs or gate results. Each arm has the same available tools, model, reasoning effort and 240-second timeout. Fresh paid API billing is excluded. Accounts and included usage are checked before each batch. All scheduled turns count once. Provider failures are reported separately from scientific judgments.

## Outcomes

The primary unit is a source/model pair. A reviewer must deliver correct consequential decisions on both twins. Compare general versus ordinary first, then specialist versus general. Also report specialist versus ordinary, critical repairs and regressions on the same drafts, intact-control harm, refusal or missing deliverables where identifiable, strict field accuracy and invalid sessions. Count gains jointly repaired by ordinary review separately. Report discordant examples with actual values, their evidence, and source counts. Weight matched pairs equally and compute percentile intervals from 10,000 resamples of whole source lineages, retaining models and twins together. Report by family and client. A single verifiable repair demonstrates a mechanism; a reliable gain needs recurrence across sources, a positive lower interval endpoint and investigation of regressions. Small cohorts support exploratory evidence only. Results describe this challenge set rather than field prevalence.

For a numeric scientific endpoint, an absolute error exceeding the larger of 0.01 in its stated units, 2% of the reference and the declared strict tolerance is material for floating concentrations, effects and rates. Counts retain their declared tolerance. Explicit decision labels are checked separately, even near a numerical boundary. The strict full-output score retains each task's requested precision and types. Case and numeric-string formatting alone cannot qualify a source.
