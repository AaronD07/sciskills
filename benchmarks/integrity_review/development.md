# Development gate

All 54 drafts submitted. Coverage and measurement each passed 18/18 on their three source pairs. No development source qualified in either family. The held-out packets are implemented for reuse, and these families receive no measured holdout sessions.

Deployment passed 16/18. Both errors were false withdrawals on intact records. On the dental study Sonnet withdrew a filed assessment whose fitting and evaluation sets matched the required 64/24 partition. Its candidate and baseline losses both equaled 1.514844. On the wearable data Luna withdrew a valid classification assessment with losses of 0.452381 for the reference and 0.416667 for the candidate. Both submissions selected the correct recipe and passed independent replay of the release artifact. These two sources qualify deployment for the preregistered comparison. All nine compromised deployment drafts were correct.
