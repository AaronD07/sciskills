# Scientific observations

The twelve CSV files are unmodified exports of separate studies in the R datasets package. Rdatasets supplies the tabular exports. The R manuals identify the original sources, variables and measurement units. The datasets package ships as part of R. Its [package description](https://github.com/wch/r-source/blob/53c67f80fd1c020154f4006e2bb76e74fa2feb60/src/library/datasets/DESCRIPTION.in) and [copying terms](https://github.com/wch/r-source/blob/53c67f80fd1c020154f4006e2bb76e74fa2feb60/COPYING) accompany the source. A copy of the license is included here.

The eligibility rules, revision ledgers, allocation tables, analytical target populations and calibration certificates in the benchmark are constructed reanalysis exercises. Only the CSV observations listed here come from the original studies. Program tests also apply deterministic changes to some inputs to check whether implementations generalize.

## Independent validation

From the repository root run `python3 benchmarks/paired_review/science_data/validate.py`. The independent checker re-reads the agent-visible observations and auxiliary tables. It recomputes each numerical report and eligibility decision with separate code. It also checks all five input/output pairs for each analytical program, including row permutation, missing observations, changed measurements and an empty input. It verifies that the permuted output agrees with the original and that at least one subset or altered input changes the expected output for every program.

The check passed for all 36 scientific tasks and all 60 program input/output pairs using NumPy 2.4.1, pandas 2.3.3 and SciPy 1.17.0. These packages are only needed for this independent cross-check. Generating packets and calculating the benchmark references use Python's standard library.
