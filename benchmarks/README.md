# Benchmarks (planned)

Goal: compare coding agents with and without a specific SciSkills instruction on the same scientific programming tasks.

For each task, record:

- task ID, problem statement, and planted issue (kept separate from agent-facing instructions)
- agent/tool and model version, date, prompts, and environment
- skill enabled or disabled
- independently scored correctness and detected issues
- elapsed time, tool calls (when measurable), and limitations

Run multiple trials and avoid interpreting one demonstration as evidence of general improvement. Benchmark cases and scoring scripts will be added later.
